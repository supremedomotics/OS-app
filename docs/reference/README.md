# UX Benchmark References

This folder archives third-party smart-home app screenshots provided by the
stakeholder **solely as usability benchmarks**.

> **Usage policy:** These are studied for navigation flows, information
> architecture, interaction patterns, screen hierarchy, and usability only.
> **No** visual assets, layouts, branding, icons, graphics, or copyrighted design
> elements are reproduced. Supreme OS implements its own unique **Aureon** design
> language (dark, architectural, gold-accented) — deliberately distinct from the
> light/monochrome aesthetic of these references.

## Patterns extracted (see blueprint §11.1)
- Room-first horizontal pager (current room centered, next room peeking).
- Room switcher as full-bleed photo hero cards in a pull-up sheet.
- **Tile-as-control**: a category tile's fill represents its value (embedded slider).
- Aggregate → detail drill-down ("Lights 7 on" → device list).
- Environment summary overlaid on the room hero (air quality / temp / humidity).
- Slide-to-confirm ("»»") for security-sensitive actions (locks, alarm).
- Quick-scene row + explicit edit/Save mode on the dashboard.
- Rich domain controls: color wheel + warm→cool brightness disc, media card with
  source badge/scrubber/transport/volume, climate dual setpoints + fan + humidifier.
- Grouped settings list with leading icons + chevron rows.
- Local vs Remote entry concept — absorbed into automatic LAN-direct vs optional
  cloud-relay routing (Supreme hides any backend endpoint configuration).
