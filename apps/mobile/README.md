# Supreme OS — Homeowner app (Flutter)

The luxury homeowner client (§11): room-first, gesture-driven, Aureon design
language. Binds to the Supreme API via `supreme_sdk` and the Aureon design system
via `aureon_flutter`. It never talks to, or shows, any backend (Home Assistant).

```bash
flutter pub get
flutter run            # device/emulator
flutter build web      # or apk / ipa
flutter test
```
